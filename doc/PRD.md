# 通用 Object Viewer 产品需求文档（PRD）

- **产品名称**：通用 Object Viewer
- **文档版本**：1.0
- **文档状态**：Draft
- **更新时间**：2026-11-12
- **目标平台**：首期为 Windows 桌面应用/组件；产品需求不绑定具体 UI 实现
- **目标读者**：产品负责人、架构师、开发工程师、测试工程师、安全评审人员

---

## 1. 文档目的

本文档定义一个通用运行时对象查看器（Runtime Object Inspector）的产品需求。该产品接收任意 .NET 对象，在调用方无需预先编写专用页面或了解对象具体类型的情况下，以类似 Visual Studio Locals/Watch 的方式浏览对象的名称、值、类型、成员、集合元素和引用关系。

本 PRD 重点回答“产品必须解决什么问题、用户如何使用、功能边界和验收标准是什么”。具体 C# 与 WPF 技术设计见 `Proposal.md`。

---

## 2. 背景与问题陈述

在自动化测试、设备调试、协议诊断、工业控制、开发工具和运行时监控场景中，工程师经常需要快速了解某个运行时对象的真实状态。现有处理方式通常存在以下问题：

1. **每种类型都要单独开发界面**：对象结构变化后，展示代码也要同步修改。
2. **普通 PropertyGrid 能力有限**：难以处理深层嵌套、集合分页、循环引用、共享引用、异常 Getter 和复杂格式化。
3. **直接反射不安全**：Getter、`ToString()` 或枚举操作可能阻塞、抛异常、触发远程查询或产生副作用。
4. **大型对象性能不可控**：一次性递归构建对象树会造成 UI 卡顿、内存膨胀，甚至进入无限递归。
5. **诊断上下文不完整**：只显示当前值，无法稳定复制路径、建立 Watch、保存快照或比较状态变化。
6. **敏感数据风险**：Token、密码、连接字符串等可能在通用浏览器中意外暴露。

因此，需要一个可复用、可扩展、安全且具备明确性能边界的通用 Object Viewer。

---

## 3. 产品愿景

将任意 .NET 对象转换为一棵**可控、可解释、可导航的观察结果树**，为桌面应用提供统一的运行时对象诊断入口，并逐步演进为支持 Watch、快照、Diff、定制适配器和远程对象的诊断平台。

产品体验应接近 Visual Studio 调试器中的 Locals/Watch，但不尝试复制完整的表达式求值器或调试器运行时。

---

## 4. 产品目标

### 4.1 核心目标

1. 接收任意 .NET 对象并展示其运行时结构。
2. 支持任意合理嵌套深度，并通过限制策略防止无限展开。
3. 对普通对象、基元、字符串、枚举、集合、字典、异常、异步对象等提供一致的查看体验。
4. 使用懒加载、分页和 UI 虚拟化处理大型对象。
5. 正确识别循环引用和共享引用，不因对象图结构而无限递归。
6. 将单个成员的读取错误隔离为局部错误节点，不影响整棵树。
7. 提供稳定对象路径，用于定位、复制、搜索、Watch、快照和 Diff。
8. 默认安全：只读、敏感值脱敏、危险操作不自动执行。
9. 允许通过 Adapter、Formatter、Policy 等扩展业务类型行为。

### 4.2 成功指标

| 指标 | 目标 |
|---|---|
| 初次展示根节点 | 常规对象在 100 ms 内出现；不得等待全图遍历 |
| 展开普通对象节点 | P95 小于 200 ms，不包含业务 Getter 自身不可控耗时 |
| 大集合浏览 | 10,000 个以上元素时仍可按页浏览，不一次性创建全部 UI 行 |
| 稳定性 | 任一 Getter、Formatter、枚举器失败不得导致 Viewer 崩溃 |
| 循环引用 | 标准循环引用测试中不产生无限递归或栈溢出 |
| 内存释放 | 关闭 Viewer 或切换根对象后，不应因订阅而长期持有旧对象图 |
| 扩展性 | 新业务类型可通过插件加入，不修改核心类型判断主流程 |
| 安全性 | 默认规则可识别并遮蔽常见 Secret/Token/Password 字段 |

> 性能指标需在约定的基准硬件、Release 构建和测试数据集上复测并固化。

---

## 5. 非目标

首期不包含以下能力：

1. 完整复制 Visual Studio 表达式求值器。
2. 执行任意对象方法或允许任意脚本。
3. 自动执行 `IQueryable`、远程查询或未知 `IEnumerable`。
4. 在无隔离措施的情况下强制终止任意同步 Getter。
5. 替代专业 JSON、XML、Hex 或数据库编辑器。
6. 默认修改生产对象或私有成员。
7. 对跨进程、跨机器对象透明访问；该能力属于后续远程代理范围。
8. 保证所有第三方对象的 Getter 都无副作用。

## 6. 用户与使用场景

### 6.1 目标用户

| 用户角色 | 主要诉求 |
|---|---|
| 软件开发工程师 | 快速检查运行时对象、定位空值和类型异常 |
| 自动化测试工程师 | 查看测试前后状态、复制路径、生成快照和差异 |
| 设备/协议调试工程师 | 查看寄存器、协议帧、状态机及嵌套设备信息 |
| 支持与诊断工程师 | 在不开发专用页面的情况下分析现场状态 |
| 组件开发者 | 为领域对象注册专用 Adapter、Formatter 或 Renderer |
| 安全/运维人员 | 确保诊断工具不暴露敏感数据或执行危险操作 |

### 6.2 典型场景

#### 场景 A：浏览任意实体

用户将一个未知具体类型的对象交给 Viewer。Viewer 立即显示根节点，用户逐层展开属性或字段，并查看声明类型与运行时类型。

#### 场景 B：浏览大型集合

对象中包含 12,500 个元素。Viewer 首次仅显示集合摘要和第一页元素，用户通过“加载更多”继续浏览，不阻塞 UI。

#### 场景 C：处理循环引用

`Department.Employees[0].Department` 再次指向同一个 Department。Viewer 显示引用节点和目标路径，而不是继续递归。

#### 场景 D：Getter 失败

读取 `Device.Status` 时抛出异常。Viewer 在该成员处显示错误类型和消息，其他成员仍可继续浏览。

#### 场景 E：搜索路径

用户搜索 `SerialNumber`。默认只检索已加载节点；用户可显式启动有边界的深度搜索，并获得完整路径。

#### 场景 F：观察动态变化

用户手动刷新选中节点，或为已加载叶子节点启用定时刷新。发生变化的值可短暂高亮。

#### 场景 G：比较测试前后状态

用户保存“Before test”和“After test”快照，Viewer 按稳定路径标识 Added、Removed、Changed 和 TypeChanged。

#### 场景 H：受控编辑

在允许编辑的环境中，用户修改白名单成员。Viewer 完成文本转换、校验、Setter 调用和重新读取；默认模式下不可编辑。

#### 场景 I：导入外部文件数据源（V0.2）

用户将 JSON/YAML/XML/CSV 文件交给 Viewer。文件被解析并物化为内存对象图后按统一体验浏览；文件中名为 `password` 的键同样被脱敏，大文件受分页与条目预算约束。

#### 场景 J：导入数据库查询结果（V1.0）

用户输入 SQL 查询，结果行物化为对象集合后统一浏览。连接字符串在展示、复制与日志中按敏感值处理。

## 8. 信息架构与主界面

### 8.1 主视图

主视图采用可展开的多列树表格：

| 列 | 说明 | 默认状态 |
|---|---|---|
| Name | 成员名、索引、Key、特殊节点名 | 显示 |
| Value | 格式化后的值或摘要 | 显示 |
| Type | 运行时类型 | 显示 |
| Declared Type | 声明类型 | 可选 |
| Access | Public/Private、ReadOnly 等 | 可选 |
| Status | Loading、Error、Changed、Masked 等 | 可选 |

示例：

```text
Name                 Value                         Type
----------------------------------------------------------------
order                {Order}                       Order
├─ OrderId           20261112001                   long
├─ Customer          {Customer}                    Customer
│  ├─ Name           "ACME"                        string
│  └─ Address        {Address}                     Address
├─ Items             Count = 12500                 List<OrderItem>
│  ├─ [0]            {OrderItem}                   OrderItem
│  ├─ [1]            {OrderItem}                   OrderItem
│  └─ Load more...
└─ Parent             ↩ reference to $              Order
```

### 8.2 工具栏

至少包含：

- 搜索框与搜索范围选择
- 刷新选中、刷新子树、刷新已加载节点
- 展开/折叠操作
- 引用显示模式
- 数值显示格式（默认、十进制、十六进制、二进制等）
- 是否显示字段、非公共成员和静态成员
- 快照与 Diff 入口（V0.2）
- 编辑模式状态（V1.0）

### 8.3 上下文菜单

- 复制显示值
- 复制原始字符串（若策略允许）
- 复制显示路径
- 复制稳定路径
- 刷新节点/子树
- 添加到 Watch（V1.0）
- 以专用查看器打开（V1.0）
- 展开到指定层级
- 查看错误详情

### 8.4 交互要求

1. 单击展开图标触发子节点加载；加载期间显示 Loading 节点和取消能力。
2. 展开失败时保留父节点，并显示局部 Error 节点。
3. 键盘支持方向键、Home/End、Page Up/Down、Enter、F2（编辑启用时）、Ctrl+C。
4. 列可调整宽度、排序与显示状态；树层级本身不允许按列排序破坏父子关系，集合内部排序必须显式启用。
5. 长字符串默认截断，允许打开全文或复制。
6. UI 不得因为后台加载完成顺序而跳回错误的选中行。

## 9. 数据类型与展示需求

| 类型类别 | 展示要求 | 展开行为 |
|---|---|---|
| `null` | 显示 `null` 和声明类型 | 不可展开 |
| 数值、布尔值 | 使用文化和显示模式格式化 | 不可展开 |
| `char` | 显示字符及可选编码值 | 不可展开 |
| `string` | 引号、转义、长度、截断提示 | 默认不可按字符展开 |
| `enum` | 名称与底层数值，如 `Running (2)` | 不可展开 |
| `DateTime`/`DateTimeOffset` | 明确时区或 Kind，支持精度配置 | 不可展开 |
| `TimeSpan`/`Guid`/`Uri` | 使用稳定格式 | 通常不可展开 |
| `byte[]` | 长度、Hex 前缀，允许专用查看器 | 不作为普通集合自动展开 |
| 普通对象 | `{TypeName}` 或 DebuggerDisplay 摘要 | 展开成员 |
| 数组/`IList` | Count 与索引项 | 分页展开 |
| 多维数组 | Rank、各维长度和多维索引 | 分页展开 |
| Dictionary | Count，按 Key/Value 展示 | 分页展开 |
| `IEnumerable` | 标记为延迟序列及风险提示 | 用户确认后分批枚举 |
| `IQueryable` | 显示 Provider/Expression 摘要 | 默认不执行查询 |
| `Task`/`Task<T>` | Status、IsCompleted、Exception；完成后可看 Result | 不阻塞等待 |
| Exception | Type、Message、StackTrace、InnerException、Data | 按专用结构展开 |
| 动态对象 | 标记动态成员来源 | 按安全策略加载 |
| 业务对象 | 由自定义 Adapter 决定摘要和子节点 | 由 Adapter 决定 |
| 敏感值 | 显示掩码和 Masked 状态 | 未授权不得展开/复制原值 |

## 10. 功能需求

### 10.1 对象输入与生命周期

- **FR-001** Viewer 必须接受 `object?` 作为根值，并允许提供根节点名称和声明类型。
- **FR-002** 设置新根对象后，必须取消旧对象的未完成加载、释放事件订阅并清空 UI 投影。
- **FR-003** 根对象为 `null` 时仍必须显示声明类型和 `null` 状态。
- **FR-004** Viewer 必须支持调用方传入查看选项、权限策略、Adapter 和 Formatter。
- **FR-005** 同一 Viewer 实例应支持多次切换根对象。

### 10.2 节点模型

- **FR-010** 每个节点必须具有 Name、Value、DeclaredType、RuntimeType、Kind、State、Path 和稳定身份信息。
- **FR-011** 必须区分声明类型和运行时类型，例如 `IAnimal` 与 `Dog`。
- **FR-012** 节点必须标识 CanExpand、CanEdit、IsLoaded、IsLoading 和 Error。
- **FR-013** 节点类型至少覆盖 Root、Null、Primitive、String、Enum、Object、Property、Field、Collection、CollectionItem、Dictionary、DictionaryEntry、Task、Exception、Reference、Error、Loading、LoadMore。
- **FR-014** 对象树必须表示“观察结果”，而不是将原对象图直接序列化到 UI。

### 10.3 成员发现

- **FR-020** V0.1 默认发现公共实例属性和字段。
- **FR-021** 可配置显示非公共成员和静态成员；默认关闭。
- **FR-022** 默认跳过索引器、方法和事件。
- **FR-023** 支持 `[Browsable(false)]`、`[DisplayName]`、`[Display]` 和排序元数据。
- **FR-024** 支持区分 Property 与 Field，并展示访问性和可写性。
- **FR-025** 支持通过成员策略隐藏、重命名、排序、脱敏或禁止读取成员。
- **FR-026** 可选支持 `DebuggerBrowsableAttribute` 和基础 `DebuggerDisplayAttribute`。

### 10.4 值读取与错误隔离

- **FR-030** 所有 Getter、字段访问、格式化和枚举操作必须被单独隔离。
- **FR-031** 成员读取失败时显示 Error 节点，至少包含异常类型和安全处理后的消息。
- **FR-032** 对 `TargetInvocationException` 应显示其实际内部异常信息。
- **FR-033** 单个成员失败不得终止同级其他成员加载。
- **FR-034** 读取操作必须支持取消信号；对于不可取消的同步 Getter，产品必须明确显示“取消不保证终止正在执行的 Getter”。
- **FR-035** 对可能阻塞的读取应支持超时状态，但不得通过不安全方式终止执行线程。

### 10.5 懒加载与分页

- **FR-040** 设置根对象时不得递归构建完整对象图。
- **FR-041** 子节点仅在用户展开、搜索显式要求或快照显式请求时加载。
- **FR-042** 可展开节点在未加载前显示占位状态。
- **FR-043** 集合必须按页加载，默认页大小为 100，可配置。
- **FR-044** 达到分页边界时显示 LoadMore 节点，且重复触发不得重复添加相同项。
- **FR-045** 应限制最大深度、最大节点数、最大字符串长度和单次枚举数。
- **FR-046** 达到限制时显示明确的 Truncated/LimitReached 节点，而不是静默丢弃。

### 10.6 集合与序列

- **FR-050** 对数组和 `IList` 使用稳定索引路径。
- **FR-051** 对支持 Count 的集合显示 Count；不得为获得 Count 而枚举未知序列。
- **FR-052** Dictionary 应显示 Key、Value 和条目索引；路径需对字符串 Key 正确转义。
- **FR-053** 未知 `IEnumerable` 默认不自动枚举，必须由用户显式启动。
- **FR-054** 枚举过程中应支持分批读取、取消、异常节点和最大条目数。
- **FR-055** 一次性序列在重新枚举前必须向用户说明风险，不保证刷新后结果相同。
- **FR-056** `IQueryable` 默认仅显示表达式/Provider 摘要，不自动调用 `ToList()` 或执行查询。

### 10.7 引用与循环检测

- **FR-060** 引用身份必须使用引用相等，而不是对象重写的 `Equals()`。
- **FR-061** 必须支持“仅检测祖先链循环”和“显示所有共享引用”两种模式。
- **FR-062** 引用节点必须显示目标路径；若目标路径尚未稳定建立，应显示可理解的对象身份占位。
- **FR-063** 值类型、字符串以及由策略认定的不可共享值不应加入普通引用身份图。
- **FR-064** 引用节点默认不可继续递归展开；后续版本可提供“跳转到目标”。

### 10.8 路径

- **FR-070** 每个节点必须具有面向用户的 Display Path，例如 `$.Items[12].SerialNumber`。
- **FR-071** 每个节点应具有成员语义路径和内部稳定身份路径。
- **FR-072** 属性名、字符串 Key 和特殊字符必须使用可逆转义规则。
- **FR-073** 用户可以复制显示路径和稳定路径。
- **FR-074** 路径规则必须形成版本化规范，以支持 Watch、快照与未来远程访问。

### 10.9 值格式化

- **FR-080** 值格式化必须独立于对象读取与 UI。
- **FR-081** Formatter 必须按优先级选择，并允许业务插件覆盖默认格式。
- **FR-082** `ToString()` 失败、阻塞或返回过长内容时不得导致 UI 崩溃。
- **FR-083** 支持 Default、Decimal、Hex、Binary、Raw string；JSON 和 Engineering notation 可在后续版本加入。
- **FR-084** 显示结果必须标记是否被截断、脱敏或格式化失败。
- **FR-085** 数值和日期格式必须允许指定 Culture；诊断路径和稳定序列化不得依赖当前 UI Culture。

### 10.10 搜索

- **FR-090** 默认搜索范围为已加载节点，可按 Name、Value、Type 和 Path 匹配。
- **FR-091** 搜索结果应展示完整路径并允许定位到节点。
- **FR-092** 深度搜索必须由用户显式启动，并配置最大深度、最大节点数、每集合最大项数和超时。
- **FR-093** 深度搜索达到边界时必须说明结果可能不完整。
- **FR-094** 深度搜索不得自动执行 `IQueryable`，也不得绕过敏感和成员访问策略。
- **FR-095** 搜索操作必须可取消。

### 10.11 刷新与实时变化

- **FR-100** 支持刷新选中节点、选中子树和全部已加载节点。
- **FR-101** 刷新不得默认重建整棵树；应优先重新读取已加载成员。
- **FR-102** 支持为已加载叶节点配置轮询周期，并设置最小周期和最大并发数。
- **FR-103** 支持订阅 `INotifyPropertyChanged` 与 `INotifyCollectionChanged`。
- **FR-104** 所有订阅必须可统一释放，优先使用弱事件或显式生命周期管理。
- **FR-105** 值发生变化时可高亮，并提供关闭高亮的设置。

### 10.12 快照与 Diff

- **FR-110** 用户可在受控边界内创建命名快照。
- **FR-111** 快照保存节点描述和格式化值，不要求原对象可 JSON 序列化。
- **FR-112** Diff 状态至少包含 Unchanged、Added、Removed、Changed、TypeChanged、Error。
- **FR-113** Diff 优先使用稳定路径匹配节点，并记录快照时采用的限制和格式化配置。
- **FR-114** 快照不得保存未获授权的敏感原值。
- **FR-115** 快照应可导出，导出格式属于 V1.0。

### 10.13 编辑

- **FR-120** 编辑能力默认关闭。
- **FR-121** 编辑开启后仍需通过策略确认成员可写；推荐仅允许标注或白名单成员。
- **FR-122** 编辑流程必须包含输入、转换、验证、Setter 调用、重新读取和结果反馈。
- **FR-123** 支持 Nullable、Enum、Boolean、Numeric、DateTime、Guid、TypeConverter 和自定义 Converter。
- **FR-124** Setter 抛出的异常必须局部显示，不得覆盖原值或使 Viewer 失效。
- **FR-125** 不支持原子回滚的对象必须明确提示编辑可能产生副作用。
- **FR-126** 编辑操作应记录审计事件，但不得在日志中写入敏感原值。

### 10.14 扩展能力

- **FR-130** 支持注册自定义类型 Adapter，并按显式优先级匹配。
- **FR-131** 支持注册 Formatter、Value Converter、Member Policy 和可选 Renderer。
- **FR-132** 插件失败必须隔离并可诊断。
- **FR-133** 核心必须提供默认 Adapter，覆盖 Null、Sensitive、Primitive、String、Enum、Task、Exception、Dictionary、Collection、Enumerable、Dynamic 和普通对象。
- **FR-134** 冲突 Adapter 的选择规则必须确定性且可观测。
- **FR-135** 未来应支持由 Source Generator 生成已知类型 Adapter。

### 10.15 外部数据源导入（2026-11-12 追加）

- **FR-140** 产品必须提供数据源 Provider 抽象（`IDataSourceProvider`），将外部数据解析并物化为内存对象后进入统一观察管线；导入能力不得侵入 Core 的对象探索主流程。
- **FR-141** V0.2 至少支持 JSON、YAML、XML、CSV 文件导入；V1.0 支持数据库查询结果导入。
- **FR-142** 导入为一次性快照语义：物化后与源解耦；重载必须由用户显式触发，且等价于重新导入。
- **FR-143** 格式解析器与解析库依赖必须置于扩展层（Extensions）；Core 保持零格式解析依赖。
- **FR-144** 导入必须受文件大小、条目数与深度预算约束；超限显示明确的 Truncated 状态，不得静默丢弃。
- **FR-145** 脱敏、路径、懒加载、分页与循环检测规则对导入数据同等生效（如 JSON 键名命中敏感规则同样脱敏）。
- **FR-146** 数据库交互限定为查询结果导入：仅执行用户显式提交的查询；连接字符串按敏感值处理，不得进入日志与复制。

## 11. 非功能需求

### 11.1 性能

- **NFR-001** 初次设置对象仅建立根节点和必要摘要，不遍历完整对象图。
- **NFR-002** 可见节点列表必须支持 UI 虚拟化。
- **NFR-003** 类型元数据和成员访问器应缓存，避免重复反射。
- **NFR-004** 后台加载不得阻塞 UI 线程；UI 集合更新必须回到 UI 调度器。
- **NFR-005** 必须设置加载并发上限，避免快速展开导致任务风暴。
- **NFR-006** 缓存不得无界持有可卸载 Assembly 或运行时对象。

### 11.2 可靠性

- **NFR-010** 任何单节点错误均不得升级为进程级崩溃。
- **NFR-011** 异步加载必须防止重复加载、过期结果覆盖和取消后回写。
- **NFR-012** 切换根对象后，旧会话产生的结果不得进入新会话。
- **NFR-013** Error、Loading、Truncated 和 Cancelled 状态必须明确可见。

### 11.3 安全与隐私

- **NFR-020** 默认只读，默认不显示非公共和静态成员。
- **NFR-021** 默认敏感名称至少包括 Password、Secret、Token、ApiKey、ConnectionString、Credential、PrivateKey、AccessToken。
- **NFR-022** 支持 `[ObjectViewerSensitive]` 等显式敏感标记和调用方自定义规则。
- **NFR-023** 脱敏值不得通过复制、搜索索引、快照、日志或导出旁路泄漏。
- **NFR-024** 不自动执行方法、索引器、`IQueryable` 和未知序列。
- **NFR-025** 插件与远程扩展需要单独的信任模型；首期只加载宿主明确注册的扩展。

### 11.4 可访问性与本地化

- **NFR-030** 支持键盘完成核心导航和复制操作。
- **NFR-031** 状态不能仅依赖颜色表达，需有文本或图标语义。
- **NFR-032** 支持高 DPI、系统缩放和明暗主题。
- **NFR-033** UI 文案可本地化；类型名、路径和诊断数据保持稳定格式。
- **NFR-034** 屏幕阅读器应能读取行名、值、类型、层级和状态。

### 11.5 可观测性

- **NFR-040** 记录匿名化的加载耗时、节点数量、取消、超时和插件失败。
- **NFR-041** 不记录对象原始值；如需诊断采样，必须由宿主显式启用并经过脱敏。
- **NFR-042** 支持查看当前会话的限制、Adapter 选择和错误摘要。

### 11.6 兼容性

- **NFR-050** 首个 WPF 实现建议基于受支持的现代 .NET LTS 版本，具体版本由项目基线确定。
- **NFR-051** Core 不依赖 WPF，便于未来复用到 WinUI、Web、日志导出和远程诊断。
- **NFR-052** 对 AOT/Trim 限制提供明确说明，并为 Source Generator 保留扩展点。

## 13. 权限与安全模式

产品应提供至少三种预设：

| 模式 | 成员范围 | 枚举 | 编辑 | 敏感值 |
|---|---|---|---|---|
| Safe | 公共实例、策略允许 | 未知序列需确认 | 禁止 | 始终脱敏 |
| Diagnostic | 可选非公共、更多 Adapter | 仍有边界 | 白名单 | 需授权查看 |
| Full Trust | 宿主明确允许的全部范围 | 可配置 | 可配置 | 仍受审计策略约束 |

Safe 应为默认模式。

## 14. 关键业务规则

1. **懒加载优先**：没有用户动作或明确任务，不读取下一层。
2. **安全优先于“看得更多”**：未知序列、查询和敏感值不自动展开。
3. **引用身份优先于值相等**：循环检测使用对象引用身份。
4. **局部失败**：成员读取失败只影响当前节点。
5. **稳定路径**：展示路径适合人读，内部路径适合机器匹配。
6. **默认只读**：编辑是显式能力，不是浏览的自然副作用。
7. **扩展有序**：Adapter 和 Formatter 使用确定性优先级，不能依赖注册偶然顺序。
8. **结果边界透明**：截断、取消、超时、未枚举、未授权均须显示。

## 15. 验收标准

### 15.1 V0.1 功能验收

1. 输入包含基元、字符串、枚举、普通对象和空值的对象时，三列信息正确。
2. 声明为接口、运行时为实现类的成员可同时显示两种类型。
3. 含自引用和双向引用的对象图不会无限递归，引用节点指向正确路径。
4. 某个 Getter 抛异常时，该成员显示 Error，其余成员正常。
5. 12,500 项 `IList` 首次只加载一页，可连续 LoadMore，索引不重复。
6. Dictionary 的 Key/Value 可浏览，字符串 Key 路径可复制且转义正确。
7. 切换根对象时，旧加载任务被取消，旧结果不会写入新对象页面。
8. Secret/Token/Password 测试字段默认脱敏，复制功能拿不到原值。
9. 达到最大深度或节点数时显示 LimitReached，而非静默结束。
10. 关闭 Viewer 后，经可控 GC 验证，不因事件订阅持有旧根对象。

### 15.2 V0.2 功能验收

1. 已加载节点搜索不触发额外 Getter。
2. 深度搜索遵守深度、节点、集合项和超时限制，并报告不完整结果。
3. 未知 `IEnumerable` 在确认前不枚举；确认后可分批、可取消。
4. `IQueryable` 不被自动执行。
5. 手动刷新只更新目标范围，值变化有可关闭的高亮。
6. 快照 Diff 正确识别 Added、Removed、Changed 和 TypeChanged。
7. 10 万可见逻辑节点场景中，UI 仅为视口创建有限数量的视觉元素。

### 15.3 V1.0 功能验收

1. 只允许策略授权的成员进入编辑状态。
2. 输入转换失败不调用 Setter，并显示明确错误。
3. Setter 失败保留原值并显示局部错误。
4. 自定义 Adapter 可覆盖默认普通对象行为，不修改 Core。
5. 插件异常被隔离并提供诊断信息。
6. Watch 路径在刷新和快照之间保持稳定，失效时有明确状态。

## 17. 风险与约束

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| Getter 有副作用或永久阻塞 | 状态改变、线程耗尽 | 默认安全模式、警告阈值、并发限制；高风险场景考虑进程隔离 |
| `IEnumerable` 触发远程查询 | 性能和成本不可控 | 默认不枚举，显式确认和硬边界 |
| TreeView 虚拟化失效 | 大数据 UI 卡顿 | 使用扁平化可见节点列表和虚拟化表格 |
| 引用图保持对象存活 | 内存泄漏 | 会话生命周期、弱事件、释放引用、受控缓存 |
| Adapter 优先级冲突 | 展示不确定 | 显式优先级、冲突诊断和自动化测试 |
| 脱敏旁路 | 数据泄漏 | 将脱敏置于读取结果进入搜索/复制/快照之前 |
| 反射与 AOT/Trim 不兼容 | 部署受限 | 保留生成式 Adapter 路径和特性标注 |
| 编辑导致生产副作用 | 业务风险 | 默认只读、白名单、审计和环境开关 |

## 19. 发布完成定义（Definition of Done）

一个版本只有在满足以下条件时才可发布：

- 对应范围内的功能需求和验收标准全部通过。
- 性能基准、泄漏测试、循环引用和错误隔离测试通过。
- 安全评审确认脱敏、复制、搜索、快照和日志无明显旁路。
- 键盘导航、高 DPI、主题和基本屏幕阅读器场景通过。
- 公共扩展接口有版本说明、示例和兼容性约束。
- 已知限制在产品界面或开发文档中明确披露。
- 示例宿主应用可展示普通对象、大集合、异常 Getter、循环引用和敏感字段。
